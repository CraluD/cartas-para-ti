# Cartas para ti

Landing page romántica, móvil primero, construida con HTML, CSS y JavaScript nativos. Cada sobre abre una carta y una galería de recuerdos.

## Personalización

Todo el texto, los títulos, las fechas, las firmas, las imágenes y sus descripciones están centralizados en `content.js`.

Los textos actuales son provisionales y pueden reemplazarse sin modificar el diseño.
